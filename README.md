Entry for the [One-Line Laugh Sprint](https://make.fun/c/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) competition on Make.fun — one original funny line (max 200 characters) on everyday life.

## The line

> I gave my Wi-Fi password to one guest, and now my router has a bigger social life than I do.

## How to run

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` (no trailing newline, so the file holds exactly the 92-character line). For local testing, set `OUTPUT_DIR` to override the output directory:

```bash
OUTPUT_DIR=/tmp/out-test python3 main.py
```

No network calls, no dependencies — Python 3 standard library only.
